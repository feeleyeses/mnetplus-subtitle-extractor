# Mnet Plus Subtitle Downloader

**为 Mnet Plus 提供简单的字幕导出。**

下载 Mnet Plus 视频提供的官方字幕和 AI 自动生成字幕，并导出为标准 UTF-8 `.srt` 文件。

**无需手动复制 Cookie。无需 HAR 文件。无需开发者工具。**

**安装扩展，直接开始下载字幕。**

[English](README.md)

> **当前推荐方式：Chrome 扩展。** 项目目前尚未发布到 Chrome Web Store，现阶段请从本仓库手动安装。

## 功能

- 自动识别当前 Mnet Plus 视频。
- 自动识别该视频实际提供的字幕轨，不使用固定语言列表。
- 显示官方字幕与 AI 自动生成字幕标记。
- 扩展界面支持 English / 简体中文；首次打开时根据 Chrome UI 语言自动选择。
- 字幕语言名称会随扩展界面语言切换显示。
- 所有字幕轨默认均不勾选，由用户自行选择。
- 支持一次生成一个或多个字幕轨并转换为 SRT。
- 自动对字幕 cue 去重并按时间排序。
- 已生成字幕会在保存前暂存在当前视频页面中。
- 支持单独保存、多选保存、多选删除以及清空全部。
- 即使系统“另存为”窗口误点取消，只要临时缓存仍在，就可以重新保存而无需重新生成。
- 在同一标签页切换到其他 Mnet Plus 视频时，会清除上一视频的临时字幕缓存。
- 如果扩展未能与当前 Mnet Plus 页面建立连接，会自动注入页面辅助脚本并重试，提升本地更新后的稳定性。

不同视频可能提供完全不同的字幕。例如某个视频可能同时提供韩语、英语、日语、简体中文和繁体中文，另一个视频则只提供其中几种。本扩展始终以 **当前视频实际返回的字幕配置** 为准。

## 安装

### 方式一：手动加载 Chrome 扩展（当前推荐）

1. 在仓库页面点击 **Code → Download ZIP**。
2. 将 ZIP 完整解压到一个固定文件夹。扩展加载后不要删除或随意移动其中的 `extension/` 文件夹。
3. 在 Chrome 地址栏打开：

```text
chrome://extensions/
```

4. 打开右上角 **开发者模式**。
5. 点击 **加载已解压的扩展程序**。
6. 选择仓库中的：

```text
extension/
```

7. 可以将 **Mnet Plus Subtitle Downloader** 固定到 Chrome 工具栏，方便使用。

仓库更新后，替换本地扩展文件，再在 `chrome://extensions/` 中点击 **重新加载** 即可。

### 方式二：Chrome Web Store

**目前尚未上架。** 是否发布到 Chrome Web Store 仍在评估中。

如果未来正式发布，本节会替换为商店安装链接。手动导入方式仍可保留作为开发版 / 测试版安装方式。

## 使用方法

1. 正常登录 Mnet Plus。
2. 打开你本人正常有权访问的 Mnet Plus 视频页面。
3. 点击 Chrome 工具栏中的 **Mnet Plus Subtitle Downloader**。
4. 扩展会自动显示当前视频真实提供的字幕轨。
5. 勾选你需要的语言；所有字幕默认均不勾选。
6. 点击 **生成选中字幕**。
7. 生成完成后，字幕会进入 **已准备好的字幕** 临时资源区。
8. 你可以单独保存，也可以多选保存 / 多选删除，或清空全部临时资源。

### 界面语言

扩展目前仅支持：

- English
- 简体中文

首次使用时，如果 Chrome UI 语言为 `zh-CN`，扩展默认显示简体中文；其他所有 Chrome UI 语言默认显示 English。右上角的 **Language** 菜单始终可用于切换语言。用户手动切换后，选择会保存在本地并在下次继续使用。

### 临时缓存

“生成字幕”和“保存字幕”是两个独立步骤。生成后的 SRT 会暂存在 **当前视频标签页** 中，因此即使浏览器或系统的“另存为”窗口里误点了取消，也不需要重新生成字幕。

以下情况会清除临时缓存：

- 刷新当前视频页面；
- 关闭当前标签页；
- 关闭浏览器；
- 在同一标签页切换到另一个 Mnet Plus 视频。

需要保留的字幕请在发生这些操作前完成保存。

## 这个扩展会做什么

正常使用时，扩展只在匹配的 Mnet Plus 媒体页面工作。它会：

- 识别当前视频及其字幕配置；
- 使用当前浏览器里已经存在的 Mnet Plus 登录状态，请求用户账号本身能够访问的字幕数据；
- 将用户主动选择的字幕 cue 转换为 SRT；
- 将已生成字幕暂存在当前视频标签页中；
- 只有在用户主动点击保存时，才把 SRT 保存到本地。

## 这个扩展不会做什么

- **不会**提供、托管或附带 Mnet Plus 视频或字幕文件。
- **不会**下载视频本体。
- **不会**绕过 DRM、订阅、付费墙、地区限制或其他技术访问控制。
- **不会**让用户访问其账号原本无权访问的内容。
- **不会**要求用户手动复制 Cookie 或 Authorization token。
- **不会**要求上传 HAR 文件。
- **不会**把用户认证信息发送给开发者。
- **不会**建立或提供公共字幕资源库。
- **不会**自动爬取无关视频或批量下载整个节目目录。

本项目是**非官方项目**，与 Mnet Plus / CJ ENM 无官方关联、授权、背书或赞助关系。

## 隐私

本扩展的设计目标是尽量减少认证信息的暴露和人工处理。

- 用户无需导出 HAR。
- 用户无需手动复制 Cookie 或 Authorization token。
- 扩展只利用当前浏览器标签页中已有的 Mnet Plus 会话，与获取字幕所需的 Mnet Plus 服务通信。
- 用户的认证信息、浏览历史和字幕内容不会发送给开发者或开发者运营的服务器。
- 已生成字幕仅暂存在当前视频标签页中，除非用户主动保存到本地。
- 当前通过 `chrome.storage.local` 保存的扩展偏好只有界面语言。

完整说明见 [PRIVACY.md](PRIVACY.md)。

请勿在 Issue、截图或日志中公开 Cookie、Authorization token 或其他会话凭证。

## 限制

- 扩展只能导出 Mnet Plus 当前视频实际提供的字幕轨。
- 如果视频本身没有可用字幕配置，本工具无法生成字幕。
- Mnet Plus 的网页内部 API 未来可能变化，从而暂时导致扩展失效。
- 扩展不下载视频内容。
- 临时生成字幕必须在当前标签页缓存被清除前保存。

## FAQ

### 为什么没有显示字幕？

当前视频可能没有提供字幕轨，或者 Mnet Plus 调整了内部字幕接口。可以先确认视频播放器本身是否提供字幕。

### 为什么扩展提示无法识别当前页面？

请确认当前打开的是 Mnet Plus 视频页面。如果刚刚更新了本地扩展，请先到 `chrome://extensions/` 点击重新加载后再尝试。当前版本在匹配页面没有已有连接时，也会自动尝试注入页面辅助脚本。

### 为什么已经生成的字幕突然没有了？

已生成字幕只是暂存在当前视频标签页中。刷新页面、关闭标签页、关闭浏览器，或者在同一标签页切换到其他 Mnet Plus 视频后都会清除缓存。

### 我在“另存为”窗口点了取消，需要重新生成吗？

不需要。只要当前页面还在、临时缓存没有被清除，重新打开扩展后再次点击保存即可。

### 为什么不同视频显示的语言不一样？

字幕语言由每个 Mnet Plus 视频自己决定，扩展不会强制使用固定语言列表。
