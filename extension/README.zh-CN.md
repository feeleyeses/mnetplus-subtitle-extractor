# Mnet Plus Subtitle Downloader — Chrome 扩展

[English](README.md)

这是本项目当前主要维护的 Chrome 扩展版本，基于 **Manifest V3**。

> 当前状态：可通过 GitHub 手动导入使用；**尚未发布到 Chrome Web Store，是否上架仍在评估中。**

## 手动安装

1. 下载或 clone 整个仓库。
2. 完整解压，并将 `extension/` 文件夹保留在固定位置。
3. Chrome 打开 `chrome://extensions/`。
4. 开启右上角 **开发者模式**。
5. 点击 **加载已解压的扩展程序**。
6. 选择本仓库的 `extension/` 文件夹。
7. 可以将扩展固定到浏览器工具栏。

更新本地扩展文件后，请在 `chrome://extensions/` 中点击该扩展的 **重新加载**。

## 界面语言

扩展目前支持：

- English
- 简体中文

首次使用时，如果 Chrome UI 语言为 `zh-CN`，扩展默认显示简体中文；其他所有 Chrome UI 语言默认显示 English。右上角的 **Language** 按钮始终保持英文，方便任何用户快速找到语言切换入口。用户手动选择后，语言偏好会保存在本地，并在下次继续使用。

字幕语言名称与 AI 自动生成标记也会跟随扩展界面语言切换。

## 使用方法

1. 正常登录 Mnet Plus。
2. 打开你本人正常有权访问的 Mnet Plus 视频页面。
3. 点击工具栏里的 **Mnet Plus Subtitle Downloader**。
4. 扩展会读取当前视频实际提供的字幕轨。
5. 所有字幕默认均不勾选；自行选择需要的语言。
6. 点击 **生成选中字幕**。
7. 扩展会抓取字幕 cue、去重、排序并转换为 SRT。
8. 生成完成后，字幕进入 **已准备好的字幕** 临时资源区。
9. 可单独保存，也可多选保存、多选删除或清空全部。

## 临时字幕缓存

扩展兼容 Chrome 的 **每次下载前询问保存位置** 设置。

“生成”和“保存”是两个独立动作。即使你在系统“另存为”窗口点击取消，只要临时缓存仍然存在，已生成字幕就不会丢失，可以再次保存。

以下情况会清除临时缓存：

- 刷新当前视频页面；
- 关闭当前标签页；
- 关闭浏览器；
- 在同一标签页切换到另一个 Mnet Plus 视频。

扩展检测到视频 ID 改变时，也会主动清除上一视频的缓存，避免不同视频的字幕资源混在一起。

## 字幕轨

扩展不会预设固定语言组合，而是读取当前视频真实的字幕配置。不同视频可能出现 `ko`、`en`、`ja`、`zh_CN`、`zh_TW`、`id` 或其他语言。

如果 Mnet Plus 标记某条轨道为 AI 自动生成，扩展会如实显示。所有轨道默认不勾选。

## 自动注入兜底

正常情况下，扩展会通过 content script 在 Mnet Plus 媒体页面工作。如果 Popup 无法连接当前页面辅助脚本，例如你刚重新加载了本地扩展但 Mnet Plus 标签页早已打开，扩展会尝试自动注入 `content.js` 并重试。

这个机制使用 Manifest V3 的 `scripting` 权限，并仅用于受支持的 Mnet Plus 页面。

## 安全与边界

扩展使用当前浏览器已有的正常 Mnet Plus 登录状态，请求当前视频字幕。

扩展不会：

- 提供或托管视频 / 字幕内容；
- 下载视频本体；
- 绕过 DRM、订阅、付费墙、地区限制或其他技术访问控制；
- 让用户访问账号原本无权访问的内容；
- 要求用户手动提供 Cookie、Authorization token 或 HAR；
- 将认证信息发送给开发者；
- 将认证信息写入导出的 SRT。

请勿在公开 Issue、截图或日志中分享 Cookie、Authorization token 或其他会话凭证。

本扩展与 Mnet Plus / CJ ENM 无官方关联。完整使用范围、隐私和版权说明见仓库根目录 README 与 `PRIVACY.md`。
