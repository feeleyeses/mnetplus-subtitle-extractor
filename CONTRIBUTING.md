# Contributing

Thanks for your interest in improving Mnet Plus Subtitle Downloader.

## Bug reports

Before opening an issue:

1. Confirm the problem occurs on a current Mnet Plus video page.
2. Reload the unpacked extension from `chrome://extensions/`.
3. Retry after refreshing the Mnet Plus page.
4. Do **not** include cookies, authorization tokens, HAR files, or other session credentials in screenshots or logs.

When reporting a bug, include:

- Chrome version;
- extension version or commit SHA;
- Mnet Plus page language / URL format;
- what you expected to happen;
- what actually happened; and
- a screenshot or console error only if it contains no sensitive authentication information.

## Pull requests

Keep changes focused and easy to review.

- Use English for source-code comments and project documentation unless editing `README.zh-CN.md` or Simplified Chinese UI copy.
- Avoid adding permissions unless they are required for an implemented feature.
- Do not add tracking, analytics, remote code execution, or developer-operated data collection without prior discussion.
- Preserve the project's current boundary: subtitle export only, no video downloading and no access-control bypass.

## Feature requests

Open an issue and explain the user problem first. Small, focused improvements are preferred over large feature bundles.
